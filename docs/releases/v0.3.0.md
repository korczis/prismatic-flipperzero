**Find: preview release.** Prismatic Pocket finds an object by name: type a title, an alias or
a code a letter at a time, and the pack's new search index answers without reading a single
title. A pack compiled for 0.2.0 still opens; this one opens in 0.2.0 too.

### What is new

- **Find by name**, the first entry of the Library: a wheel offers only the letters that have
  matches, so a query never reaches zero; the best three show under the wheel, OK lists every
  match (strong matches first: the title's first word, the code), and OK opens one.
- The pack carries a search index in two optional sections (6 440 keys, 17 220 postings,
  137 480 bytes of a 20 MB pack). The format version stays 1: the v0.2.0 app opens the new pack
  and offers no search, and this app opens a v0.2.0 pack and says it has no index; both are
  proven against the v0.2.0 tag in `tests/native/run.sh`.
- `app/core/search.c` searches with no allocation (1.2 KiB of state), checked against the
  reference `tools/pocket.py search` on every prefix of one to three letters and every key in
  full; `tools/cache-bench.sh` measures what each step reads from the card.
- The compiler no longer turns a lead-in sentence ending in ':' into a marker or a list item.
- Proven on official 1.5.1: Find typed and browsed on the device, 14 of 14 frames identical to
  the simulator (`docs/evidence/find/manifest.json`), with the pack installed through
  `just bridge push-pack`.

Hardware evidence: device and simulator frames compared on official 1.5.1 with a local build of
the tagged source (24 of 24); the manifest names the FAP's and the pack's SHA-256. The README's
device gallery was recaptured with the same build.

Each FAP ships with a `.build.json` (SDK URL and SHA-256, API, source commit); the pack ships
with its build report. Everything is listed in `SHA256SUMS`, and CI re-downloads the published
files and checks them against it.

### Install

1. Download the FAP whose API matches your firmware and `kompendium-0.3.0.pkp`; verify both
   against `SHA256SUMS`.
2. Copy the FAP to `SD/apps/Tools/` and the pack to `SD/apps_data/prismatic/` (or, from a
   checkout, `just bridge push-pack <pack>`). An older pack still works; Find needs this one.
3. Open **Apps → Tools → Prismatic**.

### Limits

Preview. Find matches prefixes on the device; the Pages explorer keeps its substring
search. Momentum builds are not yet run on hardware. The multi-pattern detector is not in this
release. No Prismatic adapter yet. Not submitted to the Flipper Apps Catalog.
