**Find, rendered pages: preview release.** The pack now carries the text the Kompendium's
readers see on its website. Earlier packs, 0.3.0 included, carried 2 214 raw template tags in
279 objects where shared passages, the technique metadata row and the chapter indexes belong.
The app is unchanged apart from its version; the pack format stays 1, so this pack opens in
0.2.0 and 0.3.0 too.

### What is new

- The compiler renders the Kompendium's page templates: shared passages pulled in with
  `{% include %}`, the technique metadata row rendered from front matter and data files, and the
  chapter indexes that loop over derived listings. The pack carries no template tag, and a tag
  outside the supported subset refuses the page instead of reaching a pack.
- Kompendium pinned at `f3d8cb3e`, its current head (was `2d08d1bf`). Relations 37 567 -> 37 899
  (links inside rendered listings now resolve), alternatives 3 792 -> 3 812.
- Device scripts wait 6 s after the loader opens the app: opening the 21 MB pack with its
  whole-pack CRC measured 3 551 ms on the device.

Hardware evidence: device and simulator frames compared on official 1.5.1 with a local build of
the tagged source (24 of 24); the manifest names the FAP's and the pack's SHA-256. The README's
device gallery was recaptured with the same build.

Each FAP ships with a `.build.json` (SDK URL and SHA-256, API, source commit); the pack ships
with its build report. Everything is listed in `SHA256SUMS`, and CI re-downloads the published
files and checks them against it.

### Install

1. Download the FAP whose API matches your firmware and `kompendium-0.3.1.pkp`; verify both
   against `SHA256SUMS`.
2. Copy the FAP to `SD/apps/Tools/` and the pack to `SD/apps_data/prismatic/` (or, from a
   checkout, `just bridge push-pack <pack>`). Replacing only the pack of a 0.3.0 install is
   enough to get the rendered pages.
3. Open **Apps → Tools → Prismatic**.

### Limits

Preview. Find matches prefixes on the device; the Pages explorer keeps its substring
search. Momentum builds are not yet run on hardware. The multi-pattern detector is not in this
release. No Prismatic adapter yet. Not submitted to the Flipper Apps Catalog.
