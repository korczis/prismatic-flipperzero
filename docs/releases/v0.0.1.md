**First Light: preview release.** A native Prismatic FAP that launches, shows the prism
mark, name, milestone and version, reads the running firmware version from the device, and
exits cleanly on Back.

### Assets

| File | Firmware | API | Tested on hardware |
|---|---|---|---|
| `prismatic-0.0.1-official-api88.2.fap` | official 1.5.1 | 88.2 | yes, see `docs/evidence/first-light` |
| `prismatic-0.0.1-momentum-api87.1.fap` | Momentum mntm-012 | 87.1 | no (build verified only) |

Each FAP ships with a `.build.json` (SDK URL and SHA-256, API, source commit) and is listed
in `SHA256SUMS`. CI re-downloads the published files and checks them against it.

### Install

Copy the FAP that matches your firmware's API to `SD Card/apps/Tools/`, then open
**Apps → Tools → Prismatic**.

### Limits

Preview only. No knowledge packs, detector, quiz, storage or host bridge yet. Not
submitted to the Flipper Apps Catalog.
