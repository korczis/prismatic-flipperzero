**Bridge: preview release.** Prismatic Pocket with a host bridge: check the device and the card,
install a pack with checksums verified on the device, and take your saved detector sessions and
quiz progress to a computer as readable JSON. The app itself is unchanged apart from its version.

### What is new

- `tools/bridge.py` (`just bridge`), specified in `docs/bridge.md`:
  - `status`: firmware, card space, the app's files, and whether the installed pack is current
    (`--md5` hashes it on the device).
  - `push-pack`: decodes the pack on the host first, refuses while an app is running, writes it
    as `<name>.part` in acknowledged 8 KiB chunks, checks its MD5 on the device, then swaps it in
    and checks again.
  - `pull`, `sessions`, `progress`: copy `sessions.jsonl` and `progress.bin` off the card and
    decode them against the pack, every object, marker and question named; counts, never a
    score.
- Proven on official 1.5.1 (`docs/evidence/bridge/manifest.json`): a 20 MB install in 479 s
  with both checks matching, pull, and a session saved through the detector decoded as keyed.

### Assets

| File | Firmware | API | Tested on hardware |
|---|---|---|---|
| `prismatic-0.2.0-official-api88.2.fap` | official 1.5.1 | 88.2 | yes, see `docs/evidence/parity` |
| `prismatic-0.2.0-momentum-api87.1.fap` | Momentum mntm-012 | 87.1 | no (build verified only) |
| `kompendium-0.2.0.pkp` | any | | yes, the same pack bytes as the parity run |

Hardware evidence: device and simulator frames compared on official 1.5.1 with a local build of
the tagged source; the manifest names the FAP's and the pack's SHA-256. The bridge is a host
program and ships in the repository, not as a release asset.

Each FAP ships with a `.build.json` (SDK URL and SHA-256, API, source commit); the pack ships
with its build report. Everything is listed in `SHA256SUMS`, and CI re-downloads the published
files and checks them against it.

### Install

1. Download the FAP whose API matches your firmware and `kompendium-0.2.0.pkp`; verify both
   against `SHA256SUMS`.
2. Copy the FAP to `SD/apps/Tools/` and the pack to `SD/apps_data/prismatic/` (or, from a
   checkout, `just bridge push-pack <pack>`).
3. Open **Apps → Tools → Prismatic**.

### Limits

Preview. Momentum builds are not yet run on hardware. No Prismatic adapter yet. Not submitted
to the Flipper Apps Catalog.
